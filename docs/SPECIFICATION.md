# AP Tutor 仕様書

- 更新日: 2026-11-11
- 対応範囲: 応用情報技術者試験の科目A・科目Bを学習する個人向けローカルWebアプリ
- 実装状態はソースコードと照合して更新する。実機確認が必要な項目は未検証と記す。

## 目的

利用者がFn+F6等で問題を撮影して画像がWaylandまたはX11クリップボードへ入ると、Ubuntuエージェントが画像をファイルに保存せず自動送信し、ブラウザーへ即時表示する。撮影画像がOSにより保存先へ書き出された場合は、監視先から送信し、受信成功後にそのファイルを削除する。直接撮影モードでは一時領域に `/dev/shm` を使う。サーバーは画像をRAMに一時保持し、AI講師が問題画像を読み、正答を急いで明かさず一段ずつ理解を支援する。問題情報と会話テキストはSQLiteに保存するが、新しい問題画像は永続化しない。

## データ

- `questions`: ID、MIMEと画像フィンガープリント、科目、AI読解内容、ヒント段階、正答開示状態、作成日時
- `chat_messages`: 問題ID、発言者、内容、日時
- `settings`: 学習モード
- 新たな撮影画像はディスクへ保存しない。サーバーメモリーに最大12枚または64MBまで保持し、再起動・上限到達で破棄する。
- SQLiteは `data/ap_tutor.sqlite3` に保存する。`data/` はGit管理対象外。過去版で作成された `data/images/` は自動削除しない。

## APIと通信

- `POST /api/screenshots`: ブラウザーから生画像データを受信
- `POST /api/agent/screenshots`: Ubuntuショートカットエージェントから生画像データを受信。`AP_TUTOR_API_TOKEN`設定時はBearer認証必須
- `POST /api/agent/heartbeat`, `GET /api/agent/status`: 常駐エージェントとデスクトップクリップボードの接続状態
- `GET /api/questions`, `GET /api/questions/{id}`, `GET /api/questions/{id}/messages`: 履歴取得
- `PATCH /api/questions/{id}`: 科目、ヒント段階、開示許可を更新
- `POST /api/questions/{id}/chat`: 会話送信
- `DELETE /api/questions/{id}`: 問題行、会話履歴、メモリー上の画像を削除
- `GET /ws`: 問題追加、解析終了、削除、設定変更を通知
- APIサーバーの既定バインド先は `127.0.0.1:8000`。

## OpenAI設定

- APIキーはサーバーの `.env` に `OPENAI_API_KEY` として設定する。
- `.env.sample` は変数名と非秘密のプレースホルダーを示し、`.env` 自体は `.gitignore` で除外する。
- モデル名は `OPENAI_MODEL` から指定し、既定は `gpt-5.4-mini`。
- AIを利用すると問題画像と会話テキストをOpenAI APIへ送信する。

## 制約と運用上の注意

- デスクトップ全画面を監視・録画せず、クリップボード上の画像またはOSのスクリーンショット保存先だけを監視する。Waylandでは `wl-clipboard`、X11では `xclip` を使う。標準保存先以外は `.env` の `AP_TUTOR_SCREENSHOT_DIR` で指定する。
- 常駐エージェントのインストールは `bash ubuntu_agent/install_service.sh` で行う。ログイン中に常駐し、画像を受信後にローカルファイルを削除する。
- 画像がメモリー上にない問題は履歴と会話テキストだけ再開できる。画像が必要なチャットは再撮影が必要。
- Ubuntu/GNOME/Waylandのポータル動作はOS版に依存する。対象実機で撮影からWebSocket表示までを確認してからMVP完了とする。
- ネットワークへ公開する運用にはTLSや認証を追加する。既定はループバック待受。
- AIの読解結果は誤り得る。特に小さな日本語文字や複雑な図表は原画像と照合する。
- 学習画像の利用条件を利用者が確認する。
